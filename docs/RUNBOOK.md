# 同窓会 実施ランブック（これがあれば回せる）

武雄高校 同窓会を「準備 → 当日 → 事後」まで回すための実務手順。
細かいタスク・準備物・予算は **幹事ダッシュボード（`admin.html`）に初期テンプレ投入済み**なので、
画面上でチェックしながら進められます。本書はその全体像と当日台本のたたき台です。

---

## 1. システム構成（だれが何を見るか）

| 画面 | URL | 対象 | できること |
|------|-----|------|-----------|
| トップページ | `/` (`index.html`) | 同級生・先生（誰でも） | **参加人数カウンター（組別）**、受付（名簿と自動照合）、**PayPay支払い** |
| 幹事ダッシュボード | `/admin.html` | 幹事のみ（PW） | **名簿（3年1〜7組）×出欠×支払い**、受付ログ、スケジュール、準備物、集金・予算、PW変更 |

データはすべて Google スプレッドシートに保存（セットアップは [`README.md`](../README.md)）。
告知文・先生向け案内のテンプレは [`ANNOUNCE.md`](./ANNOUNCE.md)。

---

## 2. 準備フェーズの進め方

開催日を **D** として、ダッシュボードの「スケジュール」タブの並びで進めます。

1. **D-4ヶ月**：実名簿投入／学年LINEで告知開始（ひろき）
2. **D-3ヶ月**：受付の希望時期を集計 → **日程確定**／会場候補リスト
3. **D-2ヶ月**：会場仮予約／**会費決定・PayPayリンク設定**／先生へ正式案内（ひろき）
4. **D-1ヶ月**：受付締切 → **人数確定**
5. **D-3週**：会場本予約・席次／**集金開始**
6. **D-1週**：進行表・名簿・受付準備／リマインド（ひろき）
7. **当日**：受付・進行・会計
8. **D+1週**：写真共有・お礼・**会計報告**

> 各ステップの細目はダッシュボードの「スケジュール」「準備物」で状態（未着手/進行中/完了）を更新しながら管理。

---

## 3. 役割分担

- **よしとみ**：サイト/連絡、日程・会場・会費、当日運営・受付・会計、名簿/集金の管理
- **ひろき**：集客（先生への声かけ＋同級生への拡散）、当時の写真・記念品・二次会の目処

---

## 4. お金まわり（集金・予算）

- 集金は **PayPay事前送金が基本**（使えない人は当日現金）。会費決定後に `config.js` へ fee / payPayLink を設定。
- 入金が来たら PayPay アプリで確認 → 名簿タブでその人を「支払い **済**」に変更（集金バーが進む）。
- 「集金・予算」タブで **収入（会費）／支出（会場・記念品など）** を予定額・実績額で管理。
- 会費の目安：会場見積り ÷ 人数 ＋ 先生招待分の補助 ＋ 予備費。
- 当日は釣り銭・領収書・電卓を受付に用意（準備物テンプレ参照）。受付リストは名簿のCSV書き出しで。

## 5. 当日の進行（たたき台）

| 時間 | 内容 |
|------|------|
| 開場・受付 | 名簿チェック（支払い済み確認）、当日現金受領、名札配布 |
| 開会あいさつ | 幹事より一言 |
| 乾杯 | 代表（先生にお願いするのも◎） |
| 歓談 | BGM・当時の写真スライド |
| 先生あいさつ | 一人ずつ近況・ひとこと |
| 集合写真 | 全員＋先生 |
| 二次会案内・締め | 次回・連絡網の確認 |

## 6. 個人情報の扱い

- フォームで集めた連絡先は本会の連絡のみに使用し、終了後に削除。
- スプレッドシートの共有は幹事のみ。ダッシュボードのパスワードは定期的に変更（設定→パスワード変更）。
