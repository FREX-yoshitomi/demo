## 2. 先生への案内（メール・手紙）

```
◯◯先生

このたび、同じ学年の卒業生で同窓会を開くことになりました。当時お世話になった先生方にもぜひお越しいただきたく、ご連絡いたしました。

日時　　12月28日〜30日のいずれかの夜（10月中旬に決定します）
会場　　武雄センチュリーホテル（予定）
会費　　先生方はご招待とさせていただきます

日程が決まりましたら、あらためてご案内いたします。
ご都合のよい日があれば、お知らせいただけますと幸いです。
```

## 3. メモ

- 「他のクラスの人にも回して」の一文は残したほうが広がりやすい
- リマインドでは、その時点の参加予定人数を入れると反応が良い
- 先生へは、担任や部活の顧問など、関わりの深かった人から送る
