## 0. 各クラスの幹事へのお願い（吉富・諸岡から送る）

```
◯組の幹事をお願いしている◯◯さんへ

年末の同窓会の件、手伝ってくれてありがとう。
お願いしたいのは、◯組のみんなに招待の案内を送ってもらうことです。

・下の「クラスのみんなへの案内文」を、クラスのLINEや個別連絡でそのまま送ってください
・連絡がつかない人がいたら、名前だけ教えてもらえると助かります
・アンケートの締め切りは 10/18（日）です

会費は事前入金制にして、入金が確認できた人から参加者用のLINEグループに招待する予定です。
会費が決まったら、また案内文を送ります。

吉富・諸岡
```

◯組 幹事 ◯◯（全体の幹事：吉富大起・諸岡拓貴）
```

```

このたび、同じ学年の卒業生で同窓会を開くことになりました。当時お世話になった先生方にもぜひお越しいただきたく、ご連絡いたしました。

日時　　12月28日〜30日のいずれかの夜（10月下旬に決定します）
会場　　武雄センチュリーホテル（予定）
会費　　先生方はご招待とさせていただきます

日程が決まりましたら、あらためてご案内いたします。
ご都合のよい日があれば、お知らせいただけますと幸いです。

幹事　吉富大起（taiki_yoshitomi@frex.works）　諸岡拓貴（joy.morooka@joy-no.com）

## 4. メモ

- クラスごとの案内は、そのクラスの幹事から送ってもらうほうが反応がよい

- 「他のクラスの人にも回して」の一文は残したほうが広がりやすい
- リマインドでは、その時点の参加予定人数を入れると反応が良い
- 先生へは、担任や部活の顧問など、関わりの深かった人から送る
