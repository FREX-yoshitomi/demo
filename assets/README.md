# assets（画像など）

## メインビジュアルの学校写真

招待ページ（`index.html`）のヒーロー背景に学校の写真を使えます。

1. 使いたい写真を **`school.jpg`** という名前でこのフォルダに置く
   （`assets/school.jpg`）
2. それだけで自動的に背景写真として表示されます

- 写真が無い場合は、紺色のグラデーション背景が表示されます（崩れません）。
- 推奨：横長（例 1600×900 程度）、文字が乗っても見やすい明るすぎない写真。
- ファイル名を変える場合は `style.css` の `.hero__photo` の `url("assets/school.jpg")` を合わせて変更してください。
