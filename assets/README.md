# assets（学校の写真）

このフォルダに次の名前で写真を置くと、サイトに自動で表示されます。置かない間は校舎の線画が表示されます。

| ファイル名 | 表示される場所 | おすすめの形 |
|---|---|---|
| `school.jpg` | トップの一番下（校舎の線画の代わり） | 横長（例：1600×900） |
| `school2.jpg` | 「一 ご挨拶」の横 | 4:3 くらい |

## GitHub のブラウザ画面からの追加方法

1. https://github.com/takeo-dousoukai/takeo-dousoukai.github.io/upload/main/assets を開く
2. 写真をドラッグ＆ドロップ（ファイル名を上の名前にしておく）
3. 「Commit changes」を押すと、1分ほどでサイトに反映されます

写真は自分で撮ったもの、または撮影者の許可をもらったものを使ってください。学校の公式サイトの写真を使う場合は、学校に確認をとるのが安全です。
