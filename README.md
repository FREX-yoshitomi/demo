# 武雄高校 同窓会 招待サイト

佐賀県立武雄高等学校 **2015年3月卒業 世代**（平成8年度生まれ・早生まれ含む）の同窓会 招待ページです。
スマホ前提のシンプルな1枚サイトで、出欠はページ内フォームから受け付けます。

- 📋 企画の全体像・やることリスト → [`PLANNING.md`](./PLANNING.md)
- 🌐 公開方法 → GitHub Pages（下記）
- 📝 出欠データの保存先 → Google スプレッドシート（Apps Script 経由）

```
.
├─ index.html      … 招待ページ本体
├─ style.css       … デザイン
├─ app.js          … 出欠フォームの送信処理（★URL設定箇所あり）
├─ gas/Code.gs     … スプレッドシート保存用のスクリプト
├─ PLANNING.md     … 企画メモ・役割分担・スケジュール
└─ .github/workflows/deploy.yml … GitHub Pages 自動公開
```

---

## セットアップ手順（全体の流れ）

1. 出欠の保存先（Google スプレッドシート）を作る
2. `app.js` に保存先の URL を設定する
3. GitHub Pages で公開する
4. 公開 URL を LINE などで共有する

---

### 1. 出欠フォームの保存先を作る（5〜10分）

1. [Google スプレッドシート](https://sheets.new) を新規作成（名前は「武雄高校 同窓会 出欠」など）
2. メニュー **拡張機能 → Apps Script** を開く
3. 既定の `Code.gs` の中身を、このリポジトリの [`gas/Code.gs`](./gas/Code.gs) の内容で**まるごと置き換え**て保存
4. 右上 **デプロイ → 新しいデプロイ** をクリック
   - 種類：**ウェブアプリ**
   - 説明：任意
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. **デプロイ** → 表示された **ウェブアプリの URL** をコピー
   （`https://script.google.com/macros/s/........./exec` の形）

> 初回は「アクセスを承認」を求められます。自分の Google アカウントで承認してください。

### 2. `app.js` に URL を設定する

[`app.js`](./app.js) の先頭を、コピーした URL に書き換えます。

```js
const RSVP_ENDPOINT = "https://script.google.com/macros/s/..../exec";
```

> 空のままだと「テストモード」になり、送信内容はブラウザのコンソールに表示されるだけで保存されません。

### 3. GitHub Pages で公開する

このリポジトリには自動公開用のワークフロー（`.github/workflows/deploy.yml`）が入っています。

1. GitHub のリポジトリ → **Settings → Pages**
2. **Build and deployment → Source** を **GitHub Actions** に設定
3. 変更を `main` ブランチに反映（マージ）すると自動でビルド・公開され、公開 URL が表示されます
   （`https://<ユーザー名>.github.io/<リポジトリ名>/`）

> 今は作業ブランチ `claude/takeo-reunion-planning-dvqypr` にあります。
> 内容を確認したら `main` にマージすると公開されます。

### 4. 共有する

公開 URL を学年 LINE グループや個別連絡で展開します（→ 集客はひろき担当）。

## 出欠の確認

回答は手順1で作ったスプレッドシートの「出欠回答」タブに1行ずつ溜まります。
名前・出欠・連絡先・希望時期などがそのまま見られるので、集計や名簿づくりに使えます。

---

## ローカルで見た目を確認する

```bash
# どちらでもOK（このフォルダで実行）
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 内容の更新

日程・会場・会費が決まったら [`index.html`](./index.html) の「開催概要」セクションの
`調整中`（`<span class="tbd">`）部分を書き換えてください。`main` にマージすると自動で反映されます。
