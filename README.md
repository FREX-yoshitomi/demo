# 武雄高校 同窓会 サイト（v2・名簿連動型）

佐賀県立武雄高等学校 **2015年3月卒業 世代**（3年1組〜7組）の同窓会サイト。
**受付・お支払い（PayPay）をサイト上で完結**させ、**名簿と参加状況**を幹事ダッシュボードで一元管理します。

- 📋 企画メモ・役割分担 → [`PLANNING.md`](./PLANNING.md)
- 📖 実施ランブック → [`docs/RUNBOOK.md`](./docs/RUNBOOK.md)

## 仕組み（v2の設計）

| 画面 | 誰が見る | 内容 |
|------|---------|------|
| トップページ `/` | 誰でも | **現在の参加予定人数（組別内訳つき・自動更新）**、開催概要、**受付フォーム**、**PayPay支払い案内** |
| 幹事ダッシュボード `/admin.html` | 幹事のみ（PW） | **名簿（3年1〜7組）×参加状況×支払い状況**、受付ログ、スケジュール、準備物、集金・予算 |

**受付の流れ**：参加者が「組＋名前」で受付 → バックエンドが**名簿と自動照合**して出欠を更新 →
トップページの人数カウンターに即反映。名簿にない名前は「名簿外」として追加され、幹事が後で確認します。

**支払いの流れ**：受付完了 → サイトのPayPayリンクから送金 → 幹事がPayPayアプリで入金確認 →
ダッシュボードの名簿でその人を「支払い済み」に変更。集金進捗はバーで見えます。

**公開されるのは人数の集計だけ**です。名簿（実名）と個人の参加状況は幹事ダッシュボードでのみ閲覧できます。

```
.
├─ index.html / style.css / app.js   … トップページ（カウンター・受付・支払い）
├─ admin.html / admin.css / admin.js … 幹事ダッシュボード
├─ config.js   … ★設定（Apps Script URL / PayPayリンク / 会費）
├─ gas/Code.gs … バックエンド（名簿照合・集計API・認証・テンプレ投入）
├─ assets/     … 学校写真（school.jpg を置くとヒーロー背景に）
└─ .github/workflows/deploy.yml … GitHub Pages 自動公開
```

## セットアップ

### 1. バックエンドを反映する（⚠️ ここ重要）

Apps Script は**コードを貼り替えただけでは公開URLに反映されません**。必ず「新バージョン」でデプロイし直してください。

1. スプレッドシート → **拡張機能 → Apps Script**
2. `Code.gs` を、このリポジトリの [`gas/Code.gs`](./gas/Code.gs) の内容で**まるごと置き換え**て保存
3. **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**
   （URLは変わりません。初回は「新しいデプロイ」→ウェブアプリ／実行=自分／アクセス=**全員**）

> 初回アクセス時に「名簿／受付ログ／タスク／準備物／予算」タブが自動生成され、
> 名簿には**サンプル名（各組8名）**が入ります。

### 2. 実名簿に差し替える

スプレッドシートの「**名簿**」タブで：
1. サンプル行（メモ列が「サンプル」）を削除
2. 実際の名前を貼り付け（**ID=連番 / 組=1〜7 / 名前** の3列があればOK。出欠は「未回答」、支払いは「未」に）

### 3. 会費・PayPayリンクを設定する

会費が決まったら [`config.js`](./config.js) を編集：

```js
payPayLink: "https://qr.paypay.ne.jp/xxxx",  // PayPayアプリ「送る」→「受け取りリンクを作成」で発行
fee: "5,000円",
```

空の間はサイト上で「調整中／準備中」と表示されます（受付は先に始められます）。

### 4. 管理パスワード

- 初期パスワード：**`takeo-kanji`**
- ログイン後、右上 **設定 → パスワードの変更** で必ず変更してください。

### 5. 公開

`main` ブランチに反映（マージ）すると GitHub Pages に自動公開されます。

## 幹事の日常運用

1. **受付が来たら**：名簿タブで出欠が自動更新されている（受付ログに履歴）。「名簿外→新規追加」は本人の行と統合
2. **PayPay入金が来たら**：名簿タブでその人の「支払い」を **済** に変更 → 集金バーが進む
3. **人数の確認**：トップページのカウンター＝名簿の「参加」の人数（組別内訳つき）
4. 名簿は **CSV書き出し** で当日の受付リストにも使えます

## 個人情報の扱い

- 公開ページに出るのは**人数の集計のみ**。実名・連絡先・個人の出欠は幹事ダッシュボード（PW保護）とスプレッドシートのみ
- 連絡先は本会の連絡のみに使用し、終了後に削除。スプレッドシートの共有は幹事のみに限定してください
