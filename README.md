# 武雄高校 同窓会 サイト

佐賀県立武雄高等学校 **2015年3月卒業 世代**（平成8年度生まれ・早生まれ含む）の同窓会サイト。
**一般ページ（誰でも閲覧）** と **幹事ダッシュボード（パスワード）** の2階建てで、
出欠・スケジュール・準備物・集金/予算を Google スプレッドシートで運用します。

- 📋 企画メモ・役割分担 → [`PLANNING.md`](./PLANNING.md)
- 📖 実施ランブック（当日台本含む）→ [`docs/RUNBOOK.md`](./docs/RUNBOOK.md)

```
.
├─ index.html        … 一般向け 招待ページ（出欠フォーム）
├─ admin.html        … 幹事ダッシュボード（要パスワード）
├─ config.js         … ★Apps Script の URL をここに設定（共通）
├─ app.js            … 出欠フォームの送信処理
├─ admin.js / admin.css … ダッシュボードの中身・デザイン
├─ style.css         … 一般ページのデザイン
├─ assets/           … 学校写真など（school.jpg を置くとヒーロー背景に）
├─ gas/Code.gs       … スプレッドシート保存＋認証＋テンプレ投入のスクリプト
├─ docs/RUNBOOK.md   … 実施手順
└─ .github/workflows/deploy.yml … GitHub Pages 自動公開
```

> **未接続でも動きます**：`config.js` の URL が空の間、一般ページはフォームが「テストモード」、
> 管理画面は「デモ表示」で全機能の見た目を確認できます（保存はされません）。

## セットアップ（全体の流れ）

1. バックエンド（Google スプレッドシート＋Apps Script）を作る
2. `config.js` に URL を設定する
3. 管理画面のパスワードを変更する
4. （任意）`assets/school.jpg` を置く
5. GitHub Pages で公開して共有する

---

### 1. バックエンドを作る（5〜10分）

1. [Google スプレッドシート](https://sheets.new) を新規作成
2. **拡張機能 → Apps Script** を開く
3. 既定の `Code.gs` を、このリポジトリの [`gas/Code.gs`](./gas/Code.gs) の内容で**まるごと置き換え**て保存
4. **デプロイ → 新しいデプロイ** → 種類「**ウェブアプリ**」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. **デプロイ** → 表示された **ウェブアプリの URL**（`.../exec`）をコピー

> 初回は「アクセスを承認」を求められます。自分の Google アカウントで承認してください。
> 初回アクセス時に「出欠回答／タスク／準備物／予算」タブと**標準テンプレが自動で作られます**。

### 2. `config.js` に URL を設定する

[`config.js`](./config.js) を編集：

```js
const APP_CONFIG = {
  endpoint: "https://script.google.com/macros/s/..../exec",
};
```

これで一般ページ・管理画面の両方がつながります。

### 3. 管理画面のパスワードを変更する

- 初期パスワードは **`takeo-kanji`**（`gas/Code.gs` の `DEFAULT_ADMIN_PASSWORD`）。
- `admin.html` を開いて初期PWでログイン → 右上 **設定 → パスワードの変更** で必ず変更してください。
- パスワードはスプレッドシート側（スクリプトのプロパティ）に保存され、幹事だけが知る形になります。

### 4. （任意）学校写真を置く

`assets/school.jpg` を置くと、招待ページのヒーローが学校写真の背景になります（詳細は [`assets/README.md`](./assets/README.md)）。

### 5. GitHub Pages で公開する

1. リポジトリの **Settings → Pages → Source** を **「GitHub Actions」** に設定
2. `main` ブランチに反映（マージ）すると自動で公開され、URL が発行されます
   （`https://<ユーザー名>.github.io/<リポジトリ名>/`）
3. 公開 URL を学年 LINE などで共有（集客はひろき担当）

## 各画面の使い方

### 一般ページ（`/`）
イベント告知＋出欠フォーム。送信内容はスプレッドシートの「出欠回答」タブに保存されます。

### 幹事ダッシュボード（`/admin.html`）
パスワードでログイン後、4タブで運用：

| タブ | 内容 |
|------|------|
| 出欠 | 回答一覧・参加/未定/不参加の集計・検索・CSV書き出し |
| スケジュール | 準備タスクを担当・期限・状態つきで管理（進捗バー、標準テンプレ入り） |
| 準備物 | 当日の持ち物チェックリスト（標準テンプレ入り） |
| 集金・予算 | 収入/支出を予定額・実績額で管理、収支を自動集計 |

各セルはその場で編集でき、変更は即スプレッドシートに保存されます。
